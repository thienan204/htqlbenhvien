# Tổng quan Hệ thống Quản lý Bệnh viện

Chào mừng bạn đến với **Sổ tay hướng dẫn** của hệ thống Quản lý Bệnh viện. Đây là nơi lưu trữ toàn bộ các tài liệu vận hành, tính năng và các thay đổi kỹ thuật của hệ thống.

## Các module chính

Hệ thống hiện tại bao gồm các module cốt lõi sau:

1. **Quản lý Kho & Vật tư y tế:** Quản lý nhập/xuất, thẻ kho, và cấu hình danh mục hàng hóa. Hỗ trợ import/export file Excel trực tiếp.
2. **Hệ thống Xử lý & Kiểm tra XML (Rule Engine):** Phục vụ việc đọc, hiển thị và kiểm tra (validate) các file XML báo cáo BHYT tự động bằng các biểu thức logic động.
3. **Quản lý Yêu cầu CNTT:** Cổng tiếp nhận và xử lý sự cố công nghệ thông tin cho các khoa phòng.
4. **Quản trị Người dùng & Phân quyền:** Quản lý tài khoản, thay đổi mật khẩu và phân bổ quyền (Role) cho từng nhân viên/bác sĩ.

> [!TIP]
> Bạn có thể chuyển đổi giữa các bài hướng dẫn thông qua menu bên trái màn hình. Dữ liệu trong trang tài liệu này có thể được cập nhật liên tục mà không cần thay đổi source code (chỉ cần thêm file Markdown).
